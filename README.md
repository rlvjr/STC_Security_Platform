# Sky Tier Capital (STC)
A Python-based security project focused on building practical cybersecurity and software development skills.

## Project Overview
Sky Tier Capital (STC) is a personal security-focused Python project designed to turn foundational programming concepts into practical cybersecurity applications.
The project is being developed incrementally, with each version expanding its functionality and security capabilities.
The initial foundation focuses on employee records, employee lookup, department classification, and active/inactive status tracking.

## Current Foundation
- Employee records using Python dictionaries
- Lists containing employee records
- Employee lookup and search
- Department classification
- Active/inactive employee status
- Continuous employee searching
- Basic input handling
- `for` loops and `while` loops
- Conditional logic
- Boolean values
- `break` statements
  
## Technology:
- Python
- Visual Studio Code
- GitHub

## Project Direction:
STC is being developed as a long-term security project that will expand alongside my Python and cybersecurity knowledge.

Future development will explore:

- Security event logging
- Authentication
- Log analysis
- Suspicious activity detection
- Security monitoring
- Database integration
- Web application development

## Development Status:
**Current Stage:** Foundation / Prelaunch
The initial employee management and lookup system is functional. Development will continue as new Python and cybersecurity concepts are learned and applied to the project.
